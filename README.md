# vivarium-monte-carlo-evolutionary-bacteriology
This work is licensed under a Creative Commons Attribution-NonCommercial-NoDerivatives 4.0 International License.  Evolutionary bacteriology demonstrates trends for the development of resistance and means of infection towards bacteria - bacteriophage relationships. This repository contains my paper upon simulating such interactions. Utilizing vivarium and agent-based modeling, an experiment was performed on F-specific bacteriophages, ampicillin, and ampicillin production-F plasmid expression in E. coli.
